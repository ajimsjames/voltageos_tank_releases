Installation Guide

Flashing Instructions & Terminal Commands

Follow the steps carefully. Unlocked bootloader and stock Motorola firmware baseline are required.

terminal@voltageos-tank:~#
IMPORTANT: Clean flash will wipe your device internal storage. Please back up all photos, files, and authenticator keys before starting.
  1. 1 Reboot phone to Fastboot Mode
    adb reboot bootloader
  2. 2 Flash Recovery Partitions
    fastboot flash boot boot.img
    fastboot flash vendor_boot vendor_boot.img
    fastboot flash dtbo dtbo.img
    fastboot flash recovery recovery.img
  3. 3 Reboot into Recovery & Format Data
    fastboot reboot recovery

    In Recovery menu: Navigate to Factory Reset > Format data/factory reset and confirm.

  4. 4 Sideload VoltageOS Package
    adb sideload voltage-6.1-tank-OFFICIAL.zip

    In Recovery: Select Apply Update > Apply from ADB, then run the command above on your computer.

  5. 5 Reboot to System

    Once installation reaches 100% or step 2/2 completes, select Reboot system now. Enjoy VoltageOS 6.1!

DIRTY FLASH NOTE: Used for upgrading from an older VoltageOS build without wiping data.
  1. 1. Reboot into Voltage Recovery
    adb reboot recovery
  2. 2. Sideload New VoltageOS ZIP
    adb sideload voltage-6.1-tank-OFFICIAL.zip
  3. 3. (Optional) Wipe Dalvik/ART Cache & Reboot
    Select "Reboot system now"
FASTBOOTD METHOD: Flash via fastbootd using extracted partitions or fastboot package.
Execute in fastboot mode:
fastboot reboot fastboot
fastboot flash boot boot.img
fastboot flash vendor_boot vendor_boot.img
fastboot flash dtbo dtbo.img
fastboot -w
fastboot reboot
